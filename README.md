# Rajeesh CP — Personal Portfolio

A responsive, static personal portfolio built with HTML, CSS and vanilla JavaScript. It is designed for free GitHub Pages hosting.

## Included
- `index.html` — page content, SEO metadata and Person structured data
- `styles.css` — responsive design and layouts
- `script.js` — mobile navigation and dynamic copyright year
- `assets/` — favicon and social sharing graphic

## Before publishing — personalize these items
1. In `index.html`, replace `YOUR-EMAIL@example.com` with your real public email address.
2. Replace the contact detail placeholders with your real details, or remove the lines you do not want to publish.
3. Replace the sample work cards with genuine projects, your role, project descriptions and verified outcomes. The current cards are clearly marked as placeholders.
4. Add your real experience, qualifications, skills and achievements to the About section.
5. After creating your GitHub Pages URL, add a canonical URL and update the Open Graph URL if desired. Do not publish a made-up URL.
6. Update the page description and social links if you add them.

## Publish free with GitHub Pages
1. Sign in or create a free account at https://github.com/
2. Create a new **public** repository.
3. For a personal site at the root domain, name the repository exactly `YOUR-GITHUB-USERNAME.github.io`.
   - Or use any repository name, such as `rajeesh-portfolio`, for a project URL ending in `/rajeesh-portfolio/`.
4. Upload all files and folders from this ZIP. `index.html` must be in the repository root.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Choose branch `main` and folder `/ (root)`, then Save.
8. Wait for the deployment to finish. Your free URL will be:
   - `https://YOUR-GITHUB-USERNAME.github.io/` for the special personal-site repository, or
   - `https://YOUR-GITHUB-USERNAME.github.io/REPOSITORY-NAME/` for a project site.

GitHub Pages is free for public repositories on GitHub Free. A custom `.com` domain is not included; this site uses the free GitHub subdomain.

## Important SEO notes
- GitHub Pages serves static files; no WordPress, PHP or server-side form processing is included.
- The email button opens the visitor's email application. Replace the placeholder email before publishing.
- Do not claim projects, client results, qualifications or statistics unless they are accurate.
- Once live, verify the exact site URL in Google Search Console and submit the sitemap if you add one. Google indexing and rankings are not guaranteed.
