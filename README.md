# Muhammed Rajeesh — Portfolio

A responsive personal digital-marketing portfolio inspired by the supplied red/orange fashion-store reference. Uses original section layouts and colors, not the reference site's branding or copy.

## Publish on GitHub Pages
1. Extract the ZIP.
2. Upload every item inside `rajeesh-red-portfolio` to the root of `MuhdRajeesh/muhdrajeesh.github.io`.
3. Keep the `assets` folder and its files in place.
4. Commit to `main`; GitHub Pages should deploy from the root folder.

Edit your email/phone in `index.html` if needed. The current contact details are based on details previously supplied in the conversation.
